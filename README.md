## Week 3: Variables and Input/Output

### Programs
1. **SimpleCalculator.java** – Performs addition, subtraction, multiplication and division.
2. **AverageCalculator.java** – Accepts a student's name and three scores, then calculates the total and average.
3. **ItemCost.java** – Calculates the total cost of an item using quantity and unit price.

### How to Compile and Run
Example:

```bash
javac SimpleCalculator.java
java SimpleCalculator
```

Repeat for the other Java programs.

## Testing
Each program should be tested with different inputs to confirm that it produces the correct output.
